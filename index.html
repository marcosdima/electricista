Preguntas Frecuentes sobre la Propuesta

¿La página web tiene algún costo fijo obligatorio por mes?

No. Al ser una página web estática optimizada, la alojamos en servidores gratuitos de alta velocidad (GitHub Pages / Cloudflare). Si elegís la modalidad de Autogestión, no pagás ningún abono mensual por mantener la página online.

¿De quién es el dominio .com.ar y las cuentas?

100% tuyos. Si elegís un dominio .com.ar en NIC Argentina, te guiamos para registrarlo a tu nombre con tu CUIT/Clave Fiscal para que siempre seas el titular oficial.

¿Puedo arrancar solo con la Página Web y sumar el Bot después?

Sí, totalmente. La propuesta está dividida en bloques independientes justamente para eso. Podés hacer primero la página web y más adelante activar el Bot de WhatsApp o la gestión de redes.

¿Cómo es la modalidad de trabajo y pago?

Se abona un 50% de anticipo para comenzar el diseño y desarrollo, y el 50% restante contra entrega una vez que revisamos todo juntos y queda publicado.
